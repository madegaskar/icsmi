# Audit Keamanan ICSMI

Audit ini dilakukan pada 3 November 2026 dan diperbarui pada 6 November 2026 untuk fitur CMS oleh AI pembuat kodenya sendiri, melalui pemeriksaan kode, automated test, dan uji HTTP lokal. Ini bukan penetration test independen dan tidak menjamin situs bebas celah. Sebelum dibuka untuk umum, sebaiknya kode diperiksa oleh orang yang paham keamanan.

Lokasi test: `tests/Feature/`.

## Temuan audit akhir yang sudah diperbaiki

1. **Host header palsu:** dapat meracuni tautan reset password. Kini host dibatasi ke `APP_URL`.
2. **Route `/storage` bawaan Laravel masih aktif untuk disk privat:** memang hanya menerima URL bertanda tangan, tetapi tidak diperlukan. Kini dimatikan.
3. **Reset password membocorkan email terdaftar:** jawabannya kini selalu sama.
4. **`.env.example` memakai `LOG_LEVEL=debug` dan email ke log:** tautan reset password bisa tertulis di log production. Nilainya kini diubah untuk production.
5. **Tidak ada cara membuat admin pertama di production:** kini tersedia `php artisan icsmi:make-admin`.
6. **Pencarian dan unduhan PDF tanpa batas permintaan:** kini dibatasi.

## Hasil pemeriksaan dependensi

Pada 6 November 2026, `composer audit` menemukan advisori untuk `symfony/http-foundation`, `symfony/http-kernel`, dan `symfony/routing`. Ketiganya sudah diperbarui dengan `composer update symfony/http-foundation symfony/http-kernel symfony/routing --with-all-dependencies` ke versi yang diperbaiki, dan Laravel tetap di 13.39.0. Setelah itu `composer audit` dan `npm audit` tidak menemukan celah. Jalankan keduanya secara berkala, terutama sebelum setiap rilis.

## Risiko tersisa

| Risiko | Tingkat | Keterangan |
|---|---|---|
| Spam, email tak diminta, atau pengisian disk lewat formulir tanpa login | Sedang | Formulir bisa mengirim email konfirmasi ke alamat orang lain, dibatasi 5 per hari per alamat dan tanpa teks dari pengirim. Pembatas per IP bisa dilewati dengan banyak IP, dan belum ada CAPTCHA. Kiriman tak terkonfirmasi dihapus setelah 7 hari jika cron terpasang |
| Identitas penulis di dalam dokumen | Sedang | Isi dan properti file tidak dibersihkan. Editor perlu memeriksa file anonim |
| File unggahan tidak dipindai antivirus | Sedang | Hanya format yang diperiksa. PDF bisa saja berisi konten berbahaya, jadi pertimbangkan pemindaian di sisi server |
| Endpoint registrasi mengungkap email terdaftar | Rendah | Pesan "email sudah dipakai" tetap muncul, dengan batas 6 percobaan per menit |
| Perubahan data lewat GET | Rendah | Tiga pengecualian: penghitung tayang dan unduhan, catatan audit ekspor, dan link verifikasi email bertanda tangan. Tidak ada data pengguna yang diubah penyerang selain status verifikasi akunnya sendiri |
| Sesi lain tetap aktif setelah ganti password | Rendah | Perangkat lain tetap login sampai sesinya berakhir |
| Editor bisa mengedit artikel terbit miliknya | Rendah | Aturan konflik kepentingan hanya berlaku pada naskah, dan perubahan tercatat di audit log |
| PDF lama tertinggal saat diganti | Rendah | File lama tidak dihapus dan tidak lagi punya tautan |
| Audit log terus membesar | Rendah | Belum ada pembersihan otomatis |
| PDF dari Media Library tidak dibersihkan | Sedang | PDF disajikan apa adanya, dan bisa memuat skrip. Hanya admin dan editor yang bisa mengunggah, tetapi pertimbangkan pembersihan atau pemindaian sebelum dibuka untuk umum |
| Impor konten mengganti menu dan beranda seluruhnya | Sedang | Pratinjau dan konfirmasi sudah wajib, tetapi tidak ada pencadangan otomatis. Ekspor dulu sebelum impor |
| Alamat halaman yang diubah memutus tautan lama | Rendah | Form memberi peringatan. Belum ada pengalihan otomatis dari alamat lama |
| Halaman yang dihapus tidak punya tampilan pemulihan | Rendah | Riwayat tetap tersimpan di database, tetapi belum ada antarmuka untuk mengembalikannya |
